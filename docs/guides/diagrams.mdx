Any fenced code block with the `mermaid` language becomes a diagram. These
examples show the most common diagram types. See
[Basic Usage](/docs/guides/basic-usage#mermaid-diagrams) for how the rendering works.

## Flowchart

```mermaid
flowchart LR
    MDX[docs/*.mdx] --> Build[build.rs]
    Nav[_nav.json] --> Build
    Spec[openapi.yaml] --> Build
    Build --> Bundle[(docs_bundle.json)]
    Bundle --> App{Shell}
    App -->|Dioxus| Wasm[WASM client]
    App -->|Topcoat| Html[Server-rendered HTML]
```

## Sequence Diagram

```mermaid
sequenceDiagram
    actor User
    participant Page
    participant Pele
    User->>Page: Scroll to diagram
    Page->>Pele: Load lazy.js
    Pele->>Pele: Import needed chunks
    Pele-->>Page: SVG
    Note over Page,Pele: Colors follow the docs theme
```

## Class Diagram

```mermaid
classDiagram
    class DocsConfig {
        +new(bundle) DocsConfig
        +with_theme_toggle() DocsConfig
        +build() DocsRegistry
    }
    class DocsRegistry {
        +get_parsed_doc(path)
        +search_docs(query)
        +page_neighbors(path)
    }
    class DocsContext {
        +current_path
        +base_path
        +navigate
    }
    DocsConfig --> DocsRegistry : builds
    DocsRegistry <.. DocsContext : resolves paths
```

## State Diagram

```mermaid
stateDiagram-v2
    [*] --> Source
    Source --> Loading : near viewport
    Loading --> Rendered : success
    Loading --> Error : invalid syntax
    Error --> Loading : source changed
    Rendered --> [*]
```
